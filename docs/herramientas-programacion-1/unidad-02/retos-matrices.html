Pensar con matrices

Ocho problemas para entrenar la cabeza antes que los dedos. En cada uno primero miras el algoritmo moverse celda por celda, entiendes por qué funciona, y solo entonces ves el código en C#.

  1. PiensaLee la pregunta y apuesta una respuesta antes de tocar nada.
  2. ObservaAvanza paso a paso. Fíjate en las variables que cambian a la derecha.
  3. PrediceCuando aparezca un signo de interrogación, responde antes de revelar.
  4. CodificaAl llegar al último paso se desbloquea el código. Compáralo con lo que viste.

Calentamiento: dos coordenadas

Una matriz se lee siempre en el mismo orden: primero la fila, después la columna. Toca una celda y mira cómo se escribe.

matriz[?, ?]

Las filas bajan y las columnas avanzan hacia la derecha. Ambas empiezan en 0.

Lo que se repite en todos

Los ocho ejercicios usan pocas ideas sobre los índices. Si las reconoces, un problema nuevo deja de parecer nuevo.

for i { for j { ... } }

Recorrer todo. El ciclo de afuera elige la fila, el de adentro recorre sus columnas.

i == j

Diagonal principal. Fila y columna son iguales.

i + j == n - 1

Diagonal secundaria. Fila y columna suman el último índice.

j > i

Triángulo superior. Evita intercambiar cada pareja dos veces.

[i, j] y [j, i]

Intercambiar los índices es transponer.

nf >= 0 && nf < filas

Antes de mirar a un vecino, comprueba que exista.

arriba++ abajo--

Límites que se encogen: el rectángulo pendiente se achica en cada vuelta.

for i { for j { for k } }

Tres ciclos cuando cada resultado necesita su propio recorrido interno.

Para trabajar en clase

1. En parejas, cada estudiante predice el resultado en papel con otra matriz. 2. Se verifica con el botón Otros números. 3. Se escribe el código sin mirar. 4. Se resuelve el reto del final de cada ejercicio.

Atajos de teclado: Flecha derecha siguiente, Flecha izquierda anterior, Espacio reproducir o pausar.
